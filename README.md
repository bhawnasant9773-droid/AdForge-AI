# LearnPro – E-learning Website Auditing & Digital Marketing Capstone

**Student:** Bhawna Sant  
**Program:** MBA – Digital Marketing  
**Case Study:** Coursera

## Project
This repository contains the redesigned/demo e-learning website and supporting capstone documents.

## Files
- `website/` – responsive HTML/CSS/JS website
- `docs/Coursera_Capstone_Report.pdf` – detailed report
- `docs/SEO_Keyword_Content_Plan.xlsx` – keyword/content plan
- `presentation/Coursera_Capstone_Presentation.pptx` – presentation
- `video/Project_Feedback_Video_Script.txt` – video script

## How to run
Open `website/index.html` in a browser.

## Deployment
Upload the `website` folder to GitHub Pages, Netlify, Vercel, or another static hosting service. The resulting HTTPS URL can be entered in the Unified Mentor **Project Deployed Link** field.

## Academic note
The LearnPro website is a demonstration redesign created for the capstone. It is not an official Coursera website and does not represent Coursera's own branding or internal performance data.
